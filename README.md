# Selin Baby Store

Selin Baby Store is a frontend e-commerce project for baby clothing, toys, and everyday essentials. It has a responsive design and a soft, colorful style.

## Features

- Browse baby products by category.
- Search for products.
- Filter and sort products by price.
- Add products to the shopping cart.
- View and manage the cart.
- Responsive design for different screen sizes.

## Technologies

- HTML
- CSS
- TypeScript
- Vite

## Getting Started

1. Install the dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal.
