# Selin Baby Store — Agent Instructions

- Use HTML, CSS, and Vanilla JavaScript with Vite. Do not use React or TypeScript.
- Keep the project frontend-only. Do not add a backend or database.
- Read `design.md` before making visual changes and follow Selin's existing design system.
- Preserve the existing product data, images, brand identity, and working features.
- Follow the project architecture and keep JavaScript organized into separate modules.
- Only `src/dom.js` may directly access or modify the DOM.
- Implement only what is included in the current task. Do not add unrelated features.
- Avoid unnecessary dependencies and explain any dependency before adding it.
- After code changes, run the available checks and report accurately which checks ran and their results.
- Never modify `CLAUDE.md` unless explicitly asked.
- Do not delete or overwrite existing files without explaining the change and getting approval.
- Work incrementally, explain changes clearly, and wait for approval before moving to the next major stage.
