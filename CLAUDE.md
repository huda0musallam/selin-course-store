# Selin Baby Store — Project Instructions

## Project

- Use HTML, CSS, TypeScript, and Vite.
- Keep the project frontend-only.
- Preserve the existing design, products, images, and features.
- Read `design.md` before making design changes.

## Code Rules

- Use semantic HTML and accessible labels.
- Use strict TypeScript. Avoid `any`.
- Keep code organized into modules, with each file having one responsibility.
- Use `src/ui/dom.ts` for shared DOM helpers.
- Product data is in `src/products/products.ts`.
- Keep search, filtering, sorting, and cart features working correctly.
- Avoid duplicated code, unnecessary dependencies, and unrelated changes.

## Workflow

- Check the project structure before making changes.
- Explain what you will change and why.
- Work step by step and explain new files and functions simply.
- Run the available checks after changes.
- Do not delete or overwrite files without approval.
- Never commit or push without permission.

## Mistakes to Avoid

- Don't use outdated file paths.
- Don't add features I didn't request.
- Don't change the project's technology without my approval.

## Communication

- Explain technical concepts in simple language.
- Treat me as a learner.
- Do not claim checks passed unless they were actually run.
